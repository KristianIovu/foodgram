# Foodgram - «Продуктовый помощник»

**Foodgram** - это веб-приложение для публикации рецептов. Пользователи могут создавать рецепты, добавлять их в избранное и формировать список покупок.

# Функциональность

## Пользовательские возможности:
- **Регистрация и аутентификация** пользователей
- **Создание, редактирование и удаление** рецептов
- **Добавление рецептов в избранное**
- **Подписка на авторов** и просмотр своих подписок
- **Формирование списка покупок** с возможностью скачивания
- **Фильтрация рецептов** по тегам
- **Поиск ингредиентов** по названию
- **Пагинация** на страницах с рецептами

## Административные возможности:
- Полный доступ ко всем моделям через админ-панель
- Поиск пользователей по email и username
- Фильтрация рецептов по автору, названию и тегам
- Отображение статистики (количество добавлений в избранное)

# 🛠 Технологии

## Backend:
- **Python 3.11+**
- **Django 4.2+**
- **Django REST Framework**
- **Djoser** (аутентификация)
- **PostgreSQL** (продакшен)
- **Gunicorn** (WSGI-сервер)

## Frontend:
- **React** (предоставлен готовый SPA)

## Инфраструктура:
- **Docker** и **Docker Compose**
- **Nginx** (веб-сервер и прокси)
- **GitHub Actions** (CI/CD)
